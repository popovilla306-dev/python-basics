# Game Store

Консольний магазин ігор, створений на Python.

## Можливості
- Перегляд доступних ігр в магазині
- Вибір товару та кількості товару
- Розрахунок загальної вартості 
- Автоматичне нарахування знижок
- Вибір способу оплати
- Показ чека

## Запуск програми
1. Встановіть Python
2. Завантажте проєкт
3. Запустіть файл main.py
